Usage

三种用法，按需选择

网页转换、命令行直接拼接、或把 Docker 配成镜像加速器。

1

网页转换

把原始链接粘贴到上方输入框，点「转换链接」，复制生成的地址即可。

# 原始
https://github.com/user/repo/releases/download/v1.0/app.zip

# 加速
https://mirror.137101.xyz/gh/https://github.com/user/repo/releases/download/v1.0/app.zip
2

命令行下载

直接在 curl、wget 或 aria2 前拼接前缀。

curl -L -O https://mirror.137101.xyz/gh/https://github.com/\
  user/repo/releases/download/v1.0/app.zip

# 断点续传
wget -c https://mirror.137101.xyz/gh/…
3

Docker 镜像源

写入 /etc/docker/daemon.json 后重启 Docker。

{
  "registry-mirrors": ["https://mirror.137101.xyz"]
}

# 重启生效
sudo systemctl restart docker

FAQ

常见问题

EdgeMirror 是否免费？有流量限制吗？

完全免费，无需注册，也没有人为的流量上限。站点运行在 Cloudflare Workers / Pages 之上，静态资源请求不额外计费，因此在合理使用范围内可以长期免费提供。

为避免被滥用为开放代理，只允许白名单内的 GitHub、Docker Hub 与 SourceForge 域名通过，其他目标会被直接拒绝。

支持哪些 GitHub 资源类型？

目前覆盖以下来源：

github.com（Releases 资产、archive 归档）· raw.githubusercontent.com（Raw 原文）· codeload.github.com（源码包）· gist.githubusercontent.com（Gist）· api.github.com（REST API）· Release 资产的重定向目标 release-assets.githubusercontent.com

Docker 镜像加速如何配置？

编辑 /etc/docker/daemon.json，加入 "registry-mirrors": ["https://mirror.137101.xyz"]， 然后执行 sudo systemctl restart docker。

之后 docker pull nginx 会自动走加速链路。也可以显式指定： docker pull mirror.137101.xyz/library/nginx:latest。

为什么某些链接转换后无法下载？

常见原因有三类：

一是目标域名不在白名单内（例如私有 CDN 或个人网盘），会被代理拒绝； 二是上游资源本身需要登录鉴权（私有仓库、私有 Release）； 三是节点临时异常，此时可在输入框下方切换其他节点后重试。

节点挂了怎么办？

页面顶部的状态灯与「节点状态」表格会实时探测各线路。若某条线路异常， 它会显示为红色，此时在输入框下方选择其他节点即可。

节点清单由服务端配置文件驱动，站长可以在不改变前端的情况下增删或替换线路， 新的节点会在下次部署后自动出现在列表中。

加速链接支持 git clone 吗？

支持。把仓库地址拼接为 git clone https://mirror.137101.xyz/gh/https://github.com/user/repo.git 即可。需要注意 clone 走的是 smart HTTP 协议，会发起多个子请求， 若上游对 git 协议有限制则可能失败。
